# Wrist Home Reflection

I used today's steps as the single headline metric and made "Start Journey" the only quick action. This follows Apple's watchOS Human Interface Guidelines for a glanceable, focused experience: the screen gives one important value first, then one timely action without copying the fuller iPhone dashboard. The larger rounded step count creates a clear hierarchy that can be read quickly on the wrist, while the single prominent button avoids forcing the user to scan a tab-style phone layout on a small display.
